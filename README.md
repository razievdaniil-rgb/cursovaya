# Медицинские изделия России — frontend

Адаптивный React-интерфейс платформы каталогизации и мониторинга медицинских изделий. Реализованы 11 маршрутов, три демонстрационные роли, каталог, сравнение, отзывы, кабинеты и аналитические состояния.

## Запуск

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run test:e2e
```

## Демонстрационные состояния

- `/catalog?state=empty` — пустая выдача.
- `/catalog?state=error` — ошибка каталога.
- `/government/sync?state=stale` — устаревшие данные.
- `/government/sync?state=error` — недоступный источник.

Авторизация локальная. Выбранная роль определяет доступ к кабинету организации или государственным разделам. Данные, сравнение и сессия сохраняются в `localStorage`.
