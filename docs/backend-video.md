# Запись backend на настоящем PostgreSQL

`scripts/record-backend-demo.mjs` записывает настоящие HTTP-запросы к
запущенному NestJS, прямые SQL-запросы через Prisma и страницы интерфейса.
Видеозапись не содержит подменённых ответов API. Она включает все 52 операции
OpenAPI, ожидаемые отказы в доступе, CRUD, модерацию, ротацию сессии и
обращения к внешним источникам. Повторный прогон создаёт новые demo-аккаунты.

## Подготовка

Используйте **отдельную** базу с именем `cursovaya_demo_video_<суффикс>`.
Скрипт проверяет имя до любых изменений. Примените все миграции, выполните
seed с собственным `SEED_DEV_PASSWORD`, создайте администратора
`admin@video.example.test` командой `npm run admin:create`.
Демонстрационные пользователи seed и внешние записи явно различаются в видео.

Запустите backend с этой БД и доверенным сертификатом источника:

- `DATABASE_URL` — отдельная demo БД PostgreSQL;
- `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET` — случайные секреты от 32 символов;
- `NODE_EXTRA_CA_CERTS` — абсолютный путь к `backend/certs/russian-trusted-ca.pem`;
- `FRONTEND_ORIGINS=http://127.0.0.1:4173`;
- `NODE_ENV=development`, `PORT=3000`;
- `THROTTLE_DEFAULT_LIMIT=3000` — только для плотного демонстрационного прогона;
- не задавайте локальные файлы провайдеров: внешние данные читаются из сети.

Соберите frontend с `VITE_API_URL=http://127.0.0.1:3000/api/v1` и запустите
`npm run preview -- --host 127.0.0.1`. Установите компонент записи:
`npx playwright install ffmpeg` (и Chrome, если его ещё нет).

## Запись

Передайте окружение, не записывая пароли в файлы репозитория:

- `DATABASE_URL` — та же demo БД;
- `DEMO_PASSWORD` — seed-пароль;
- `DEMO_ADMIN_PASSWORD` — пароль созданного администратора;
- `DEMO_OUTPUT` — абсолютный путь к каталогу видео **вне репозитория**;
- необязательно `DEMO_API_URL`, `DEMO_WEB_URL`, `DEMO_HOLD_MS` (по умолчанию 3200 мс).

Из корня: `node scripts/record-backend-demo.mjs`.

Результат: `backend-full-demo.webm`, `backend-demo-transcript.json`,
`chapters.txt`, `final-frame.png`. Пароли, токены и cookies скрыты.
JSON содержит фактические HTTP-статусы и полные очищенные ответы;
в кадре длинные массивы сокращаются для читаемости. Видео без звука,
с пояснениями на русском. Для MP4:

```sh
ffmpeg -i backend-full-demo.webm -c:v libx264 -crf 21 -pix_fmt yuv420p -movflags +faststart backend-full-demo.mp4
```

## Честные ограничения демонстрации

- Реестр импортируется ограниченно: пять настоящих записей, а не полный обход.
  Поэтому `partial` ожидаем. SQL показывает сохранённые внешние ID.
- Номенклатура загружается из официального ZIP/XML. Недоступность ведомства
  показывается фактическим 502; она не заменяется фиктивным успехом.
- Без credentials почтового сервиса запрос восстановления возвращает 503.
  Для показа **подтверждения** одноразовый токен готовится прямо в demo БД,
  с отдельной поясняющей заставкой. Это не демонстрация отправленного письма.
- Скрипт меняет только указанную demo БД. Списки и сравнения, созданные во
  время показа, удаляются через API; новый отзыв и внешние записи сохраняются.
